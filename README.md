# reactjs-question-answer-bot-538-2372

This project includes a React frontend that can call Google Gemini directly from the browser for demonstration purposes.

Important:
- To enable direct Gemini calls, add REACT_APP_GEMINI_API_KEY to the frontend `.env` (inside reactjs_chatbot_frontend).
- This is insecure for production; keys embedded in frontend code can be exposed. Prefer a backend proxy for production deployments.

See reactjs_chatbot_frontend/README.md for detailed setup and warnings.
